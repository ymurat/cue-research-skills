## Final checks before submission

- Every editor and reviewer point has a response, or is explicitly marked as not applicable.
- Each described change is present in the submitted revision.
- Page, line, and section references match the final file and the venue's requested version.
- New analyses or evidence are reported only if they were actually completed and documented.
- Any disagreement is explained respectfully and supported by evidence or a clear rationale.
- The response file and any quoted review material are not included in a public repository unless explicit authorization permits it.
