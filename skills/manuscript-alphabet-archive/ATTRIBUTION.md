# Attribution and provenance

This original skill was developed for Murat Yılmaz with AI-assisted drafting
and review, then generalized for public use from a local manuscript-alphabet
archive pilot. The public package retains the workflow's source-provenance,
uncertainty, and validation principles while removing personal paths and
dependencies on that pilot's files.

No upstream skill text, third-party OCR scripts, manuscript scans, catalog
reproductions, or extracted glyph dataset is bundled. The Garrett 52B note is
a newly written account of the pilot's scope and limits, not a transcription
or an endorsement by the manuscript's holding institution.
